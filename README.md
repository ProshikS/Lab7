# Задание 6

## Задача 1

### Текст задачи
Даны упорядоченные списки L1 и L2. Вставить элементы списка L2 в список L1, не нарушая его упорядоченности.

### Алгоритм решения

Пользователь вводит два упорядоченных по возрастанию списка целых чисел (через пробел). Ввод проверяется: числа должны быть целыми, список не пуст и отсортирован по возрастанию. Затем выполняется слияние двух отсортированных списков в один. Для этого используются два индекса: сравниваются текущие элементы L1 и L2, меньший добавляется в результирующий список. После завершения одного из списков оставшиеся элементы другого добавляются в конец. Результат заменяет содержимое L1 и выводится на экран.

# Задание 7

## Задача 1

### Текст задачи
Подсчитать количество элементов списка L, у которых равные «соседи».

### Алгоритм решения

Пользователь вводит элементы списка (целые числа через пробел). Создаётся двусвязный список LinkedList<int>. Если в списке менее трёх элементов, счётчик равен 0. Иначе перебираются все узлы, начиная со второго и заканчивая предпоследним. Для каждого узла проверяется, равны ли значения его предыдущего и следующего элементов. Если да, счётчик увеличивается. Результат выводится на экран.

# Задание 8

## Задача 1

### Текст задачи
Определить для каждого блюда, какие заказывали все посетители, некоторые, и какие не заказывал никто.

### Алгоритм решения

Пользователь вводит количество блюд и их названия. Затем вводится количество посетителей. Для каждого посетителя вводится список заказанных блюд через запятую. Заказы сохраняются в виде множеств HashSet<string>. Для каждого блюда из общего списка подсчитывается, сколько посетителей его заказали. Если количество равно общему числу посетителей, выводится «заказывали все посетители». Если больше нуля, но меньше общего числа — «заказывали некоторые посетители (k из N)». Если ноль — «не заказывал никто».

# Задание 10

## Задача 1

### Текст задачи
Вывести фамилии и имена трёх лучших участников многоборья (и всех, у кого одинаковый балл с третьим местом).

### Алгоритм решения

Пользователь вводит количество участников N. Для каждого участника вводится строка формата: Фамилия Имя Балл1 Балл2 Балл3 Балл4. Ввод проверяется: ровно 6 частей, баллы — целые числа от 0 до 10. Создаётся список объектов Participant, содержащих фамилию, имя и массив баллов. Для каждого участника вычисляется сумма баллов. Список сортируется по убыванию суммы баллов с помощью метода Sort и компаратора CompareParticipants. Определяется пороговый балл: если участников не менее трёх, берётся сумма баллов третьего участника; иначе — последнего. Затем выводятся все участники, у которых сумма баллов больше или равна пороговой.
